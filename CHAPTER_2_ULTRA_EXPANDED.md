# LESSON 2: SYSTEMS THINKING FOR BEGINNERS

# Written to explain why farms (and businesses) are harder than they look

"""
Everything is a system.

A car is a system.
A farm is a system.
A business is a system.
Your body is a system.
Your mind is a system.

INPUTS → PROCESS → OUTPUTS

        """Add seeds (input)"""
        self.seeds += seeds

        """Add water (input)"""
        self.water += liters

        """Add labor (input)"""
        self.labor_hours += hours

        """Convert inputs to outputs (process)"""

        theoretical_yield = min(
            self.seeds,
            self.water / 10,

        self.time_allocation = {

            'coordination': 0.30,          # 30% - meetings, scheduling, coordination
            'problem_solving': 0.10,       # 10% - actual judgment and decision-making
        }

    def calculate_value_creation(self):
        """
        Here's the brutal truth:

        60% of their time is spent on tasks a $200 sensor can do better
        30% of their time is spent on coordination an app can handle
        10% of their time is spent on actual human judgment

        So this worker is creating REAL value only 10% of the time.

        Is that their fault? NO.
        It's the SYSTEM's fault.

        The system is wasting 90% of their potential.
        """
        value_hours = self.hours_per_day * self.time_allocation['problem_solving']
        waste_hours = self.hours_per_day * (1 - self.time_allocation['problem_solving'])

        return {
            'value_hours': value_hours,      # 0.8 hours per day
            'waste_hours': waste_hours,      # 7.2 hours per day
            'efficiency': value_hours / self.hours_per_day  # 10%
        }


class AutomatedFarmWorker:
    """
    The same worker, after automation.
    Notice: They still have a job.
    But now they're doing DIFFERENT work.
    """

    def __init__(self, name):
        self.name = name
        self.hours_per_day = 8
        self.time_allocation = {
            'monitoring_systems': 0.20,     # 20% - Watching dashboards, checking alerts
            'decision_making': 0.40,        # 40% - Actual judgment calls
            'optimization': 0.30,           # 30% - Improving processes
            'training': 0.10,               # 10% - Learning new skills
        }

    def calculate_value_creation(self):
        """
        Now look at the time allocation:

        90% of their time is spent on high-value activities
        Only 10% is spent on monitoring (which still requires human oversight)

        Same person.
        Same 8 hours.
        But now they're creating 9x more value.

        And because they're more valuable, they:
        - Get paid more
        - Have better job security
        - Do more interesting work
        - Feel more fulfilled

        This is what automation ACTUALLY does.
        """

            self.time_allocation['monitoring_systems'] +
            self.time_allocation['decision_making'] +
            self.time_allocation['optimization']
        )

        return {
            'value_hours': value_hours,      # 7.2 hours per day
            'efficiency': value_hours / self.hours_per_day  # 90%
        }


# Now let's scale this across your entire workforce:

def calculate_workforce_impact(num_workers=350):
    """
    You have 350 workers.
    Let's see what automation actually does.
    """

    # BEFORE AUTOMATION
    traditional_workers = [FarmWorker(f"Worker{i}") for i in range(num_workers)]
    total_value_hours_before = sum(
        w.calculate_value_creation()['value_hours']
        for w in traditional_workers
    )

    # AFTER AUTOMATION
    # Same number of workers, but now they're more effective
    automated_workers = [AutomatedFarmWorker(f"Worker{i}") for i in range(num_workers)]
    total_value_hours_after = sum(
        w.calculate_value_creation()['value_hours']
        for w in automated_workers
    )

    # Calculate the opportunity:
    # With 9x more productive workers, you can now handle 9x more operations
    # Which means you need MORE workers, not fewer

    productivity_multiplier = total_value_hours_after / total_value_hours_before

    # If you expand operations to match this new capacity:
    workers_needed_for_expansion = int(num_workers * productivity_multiplier)

    return {
        'workers_before': num_workers,
        'value_hours_before': total_value_hours_before,
        'value_hours_after': total_value_hours_after,
        'productivity_increase': productivity_multiplier,
        'workers_after_expansion': workers_needed_for_expansion,
        'net_jobs_created': workers_needed_for_expansion - num_workers
    }

Thank you for calling my references. I'm glad they confirmed the value.

   undercharging for strategic reasons that no longer apply.

— Moteka Tlhoro
Founder, Tlhoro Systems
AI Engineering & Predictive Analytics

*Fear Voice: DON'T. You already have the contract! Fifteen million! Take it!*

Pieter van der Merwe:

You have balls. I respect that.

When can you start?

— Pieter

Someone who built in the light.
Someone who charged what he was worth.

Next Friday: The rest of my life."

The cursor blinked.

He typed.

And in a converted garage in Warrenton, a man who had spent three years hiding finally decided to be seen.
